## 排序说明

- **V1.1 已并入 DEV-PLAN 阶段 2.5**：全是"已经付了 UI 成本却没兑现"的欠账，性价比最高，紧随 DEV-PLAN 阶段 2 执行；A1（Viewbar）依赖拾取，可与 DEV-PLAN #4 同期穿插。
- **V1.2 中灯光（#8）优先级最高**：渲染品质的所有上限都卡在"只有一根平行光"上；贴图（#9）次之。
- **V1.3 的分享链接（#14）是轻量高价值项**：不需要账号体系也能做，可提前到 V1.2 之后单独插队。
- **V2 全部押后**：CSG/骨骼动画/协作都是数量级工作量，且依赖前面版本的 store 与时间轴稳定。
- **工程横切里代码分割最急**：随 DEV-PLAN #19（导入模型）会进一步增大 bundle，宜在导入功能前先做。
