3D 场景编辑器 · 产品需求文档

一个在浏览器中快速搭建、编辑、预览 3D 场景的轻量工具。面向前端开发者、技术原型设计师、3D 场景爱好者，分三期交付。

1. 背景与目标

1.1 要解决的问题

Three.js 生态的文档与示例虽然丰富，但"在浏览器里从零拼一个 3D 场景"对非专业用户来说仍然有门槛： 几何体、材质、光照、坐标变换散落在不同的 API 里，调一个效果往往要反复改代码、刷新页面。

同时，专业级工具（Blender、Unity）体积大、启动慢、学习曲线陡，不适合"画一个正方体、摆两个球、看一下光效"这种轻量的探索需求。

1.2 目标用户与核心任务

用户画像触发点核心任务完成标志
前端开发者 需要给活动页面加一个 3D 效果，想先快速摸索灯光和材质组合 在可视化编辑器里搭场景 → 调到满意 → 拿到 JSON 配置或截图 在 10 分钟内产出一段可用的 Three.js 配置片段或导出图片
技术原型设计师 有一个空间交互的概念想给团队看，不想用 Figma 假 3D 快速摆放几何体 → 拖拽调整 → 邀请别人链接进来预览 生成一个带可交互预览的在线链接
3D 初学者 在学 Three.js，想把"旋转一个物体"这个概念变成可感知的动手练习 选中物体 → 拖动 Gizmo → 看到坐标值实时变化 理解 position / rotation / scale 三个坐标的区别与效果

1.3 产品决策与可观察结果

产品决策：做一个单用户、本地优先的 Web 端 3D 场景编辑器，而不是云端协作工具或专业建模软件的替代品。聚焦"摆几何体 + 调属性 + 预览"这一条最短路径，在此之上扩展。

可观察的结果：用户打开编辑器 → 3 秒内看到一个可操作的场景 → 能在不写任何代码的情况下添加、选中、移动、删除几何体 → 能撤销自己做过的动作 → 能把场景以 JSON 文件保存到本地磁盘。

2. 范围与分期边界

2.1 产品合同

维度内容
主要用户单用户本地编辑（P0/P1/P2 全程）
共享对象一个场景（Scene），包含 N 个对象（Object），每个对象有类型、变换、材质、可见性
进入条件访问编辑器 URL，场景默认含一个地面 + 一个示例方块
完成条件用户做出并保存了自己的场景，且能再次打开继续编辑
故障恢复任意操作可撤销；页面崩溃不丢失上次保存的文件

2.2 分期定义

阶段 定位 核心交付 可观察的完成标志
P0 MVP 闭环 Canvas 场景 + 5 种基础几何体 + Gizmo 变换 + 属性面板 + 撤销重做 + JSON 导出 用户能用编辑器从零搭一个场景并导出 JSON 文件，在另一个会话里重新导入
P1 效率与丰富度 更多几何体 + 场景保存/加载 + 快捷键 + 材质切换 + 对象列表完善 用户能在 15 分钟内独立完成一个包含 10+ 对象、3 种材质的小场景，并保存为多个版本
P2 进阶能力 导入 GLB/GLTF + 多物体批选 + 分组/父子 + 时间轴动画 + 渲染导出（PNG / 静态 HTML） 用户能把编辑器当作"轻量场景可视化工具"使用，产出带交互的在线演示页

2.3 明确排除的范围

  • 多人实时协作（WebRTC / CRDT）— 放在 P2 之后再评估，不属于当前产品合同
  • 顶点/边/面级别的建模（Subdivision、Edge Loop、Bevel）— 这是建模软件的职责
  • 物理引擎（重力、碰撞）— 属于游戏引擎范畴，P2 不做
  • 骨骼动画、Morph Target — 需要更完整的资产管线，超出当前范围
  • 账户系统、云端自动保存 — P0/P1/P2 全程本地优先，显式提供"保存到文件"按钮

3. 产品模型

静态 UI 版实现说明（2026-11）：当前代码库已完成 P0 / P1 / P2 的全部 UI 壳（含时间轴、树形列表、材质 / 环境区、渲染导出菜单），并追加以下超出原 PRD 的内容：画布右上角视图控制条、地板降级为环境元素（环境区可显隐 / 换色）、对象锁定字段与图标、列表搜索框与拖拽把手、时间轴播放头 / 多轨 / 时长标注、Vec3 分组折叠与重置。交互与功能实装按 docs/DEV-PLAN.md 推进，后续演进见 docs/ROADMAP.md。本文档相应小节已同步（标注「静态版」处）。
功能实装进度（截至本次更新）：P0 主链路已打通——状态 store、添加 / 复制 / 删除对象、视口拾取选中、Gizmo 三种变换、撤销重做、显隐与锁定、JSON 导出 / 导入、localStorage 自动草稿、环境预设；效率项已补：列表搜索过滤、Vec3 重置、快捷键帮助浮层、对象右键菜单与重命名弹窗、视图控制条（四个视角 + 实体 / 线框）。尚未实装：对象列表拖拽排序（5.4）、材质类型切换（5.3）、方向键微移、离开页面提示。

3.1 界面区域

编辑器采用经典三栏布局，各区域职责单一、互不重叠：

┌─────────────────────────────────────────────────────────┐ │ [工具栏 · Toolbar] 变换模式 | 撤销/重做 | 保存/清空 │ ├──────────┬──────────────────────────────┬──────────────┤ │ │ [视图控制条]│ │ │ 资源库 │ │ 属性面板 │ │ 对象列表 │ 3D 画布 │ 名称/颜色 │ │ (240px) │ (Canvas + Gizmo) │ 位置/旋转 │ │ │ │ 缩放/材质 │ │ │ │ (260px) │ ├──────────┴──────────────────────────────┴──────────────┤ │ [时间轴 · Timeline]（静态壳已铺，见 6.4） │ ├─────────────────────────────────────────────────────────┤ │ [状态栏 · StatusBar] 对象数 | 选中状态 | 快捷键提示 │ └─────────────────────────────────────────────────────────┘

3.2 核心对象模型

概念定义唯一性
Scene一个 3D 世界，包含若干 Object、全局光照、相机、环境设置单实例，随会话存在
SceneObject场景中的一个可渲染对象（几何体 + 材质 + 变换）id 唯一标识，生成后不变
PrimitiveType内置几何体类型的枚举（box / sphere / cylinder / cone / torus / …）枚举值固定，扩展即加新值
TransformModeGizmo 的三种工作模式：translate / rotate / scale三选一，全局共享
HistoryEntry一次可撤销操作产生的快照最多保留 50 条，超出时丢弃最旧

3.3 默认场景

首次打开编辑器或点击"清空"后，场景重置为以下内容，让新用户看到一个"已经跑起来"的 3D 世界，而不是黑屏：

  • 一个无限网格地面（y = 0）
  • 一个程序化天空（sunPosition 在东北方向）
  • 环境光 + 方向光（方向光产生阴影）
  • 一块 20 × 20 的地板平面（环境元素，静态版已实装：不进对象列表、不可选中删除，由属性面板「环境 → 地面」控制显示 / 隐藏与颜色）
  • 一个示例方块，位于 (0, 1, 0)，颜色为品牌蓝
  • 轨道相机初始位置 (8, 8, 12)

4. 功能需求（P0 · MVP 闭环）

本章按模块组织，覆盖 P0 最小可用路径。每条需求标注触发条件、处理规则、结果与状态变更。

4.1 Canvas 场景视图

维度内容
Purpose用户看到并操作 3D 世界的主画布
Layout居中占满编辑器主区域（左侧 240px + 右侧 260px 之外的全部空间），带阴影和圆角边框
Trigger编辑器页面加载即渲染，无需用户额外操作
Processing
  • 使用 WebGL 渲染器，开启抗锯齿与阴影映射
  • 相机默认使用透视投影，初始 fov = 50，位置 (8, 8, 12)
  • 视角切换：透视 / 前 / 顶 / 右四个预设；后三者使用正交相机（前视沿 -Z、顶视沿 -Y、右视沿 -X）
  • 着色切换：实体（使用各对象当前材质）/ 线框（强制各对象当前材质启用 wireframe），只作用于用户对象，不影响天空 / 网格 / 地面
  • OrbitControls 默认启用，支持左键旋转、右键平移、滚轮缩放；切换正交视角后仍可旋转缩放（跟随当前 default camera）
  • 滚轮缩放上下限：距离相机 3 ~ 60 个世界单位
  • 极角限制：相机始终在地平面上方，不允许翻到地下
Result场景可见，用户可以自由观察、切到正交视角精确定位，且不会误翻到地下
ExceptionsWebGL 不可用时显示一张提示卡片，告知"当前浏览器不支持 WebGL"

4.2 内置几何体（Primitive）

P0 提供 5 种基础几何体。每种几何体有默认颜色、默认初始位置，添加即选中。

类型 标识 默认尺寸 默认颜色 默认初始位置
长方体box1 × 1 × 1#6366f1 蓝(0, 1, 0)
球体sphere半径 0.5#f59e0b 橙(0, 1, 0)
圆柱cylinder半径 0.5，高 1#10b981 绿(0, 1, 0)
圆锥cone半径 0.5，高 1#ef4444 红(0, 1, 0)
圆环torus主半径 0.4，管半径 0.15#8b5cf6 紫(0, 1, 0)
扩展提示：P1 继续加类型时（tetrahedron、octahedron、plane、ring…），只扩展枚举和默认值映射表，不改核心逻辑。
P1 默认值：资源库已铺出全部 11 种几何体卡片；六种扩展类型的默认 color / position / rotation / scale 已补齐，统一由默认值映射表消费，参数见 5.1（DEV-PLAN #12）。

4.3 添加对象

Trigger
维度内容
Purpose把一个新几何体放入场景
用户在左侧「资源库」点击一个几何体卡片
Processing
  1. 生成唯一 id（规则：obj_ + 8 位随机十六进制）
  2. 根据类型查默认值映射表，填充 color / position / rotation / scale
  3. name 字段自动生成为：{中文名} {场景内同类型计数 + 1}，如"球体 1"、"球体 2"
  4. 写入 store，同时创建一条 HistoryEntry（见第 7 节共享规则）
Result新对象立刻出现在场景中，被自动选中，Gizmo 绑定到该对象
Exceptions同类型计数为 0 时从 1 开始，不出现"球体 0"

4.4 选中与取消选中

触发方式行为
点击场景中的几何体该对象成为当前选中，其他对象取消选中
点击锁定（locked）的对象已实装：视口拾取跳过锁定对象，点到它会穿透选中后方未锁定对象；锁定对象只能通过对象列表选中，且选中后不显示 Gizmo
点击左侧对象列表的某一行同上；若对象被标记为不可见，则不响应画布点击，但仍可通过列表选中
点击画布空白处清空选中，Gizmo 消失
按 Esc清空选中，Gizmo 消失（未实装；当前 Esc 仅用于关闭浮层 / 弹窗）
点击「资源库」卡片（添加对象）新添加的对象自动成为选中

选中的视觉反馈：被选中的对象材质 emissive 通道会有一个低频脉冲发光（频率 ≈ 0.64 Hz，emissiveIntensity 在 0.03 ~ 0.23 之间缓动），帮助用户在场景中定位当前选中。

4.5 Gizmo 变换（TransformControls）

Trigger
维度内容
Purpose让用户通过拖拽来调整对象的 position / rotation / scale
场景中存在选中对象时，Gizmo 自动显示并绑定到该对象
Processing
  • Gizmo 三种模式：平移（箭头）、旋转（圆环）、缩放（方块）
  • 模式切换：点击顶部工具栏的对应按钮，全局同一时刻只有一个模式生效
  • 拖动 Gizmo 时，对象的 position / rotation / scale 实时变化
  • 属性面板中的数值显示随拖动同步刷新（双向绑定）
  • 松开鼠标那一刻，生成一条 HistoryEntry（撤销的粒度是"一次完整的拖拽"，不是每帧一个快照）
Result用户通过拖拽 Gizmo 看到对象移动/旋转/缩放，并能通过属性面板精确读数
Exceptions
  • 缩放模式下，对象的 scale 不允许变成负数（镜像翻转）— 拖动向下限夹紧到 0.01
  • Gizmo 激活期间暂停 OrbitControls 的拖拽旋转，避免两者冲突

4.6 属性面板

属性面板只在有选中对象时显示；未选中则显示"选中对象以编辑属性"的空状态提示。

字段 类型 默认值 交互与校验规则
名称 name文本"{类型中文名} {序号}"任意字符串，长度 1 ~ 64；实时可编辑
颜色 color色板选择按类型查表十六进制 #RRGGBB；点击色板弹出系统取色器
位置 position三元数字 (X, Y, Z)(0, 1, 0)每个输入框 step = 0.01；空值不允许提交
旋转 rotation三元数字 (X, Y, Z)(0, 0, 0)单位为弧度；输入值直接覆盖 rotation；不做归一化
缩放 scale三元数字 (X, Y, Z)(1, 1, 1)step = 0.1；下限 0.01，不允许 0 或负数
可见 visible复选框true取消后对象不渲染，但仍在列表中
锁定 locked复选框false已实装。锁定后：视口点击拾取跳过、删除前需先解锁；列表内仍可选中（解锁入口）；选中的锁定对象不显示 Gizmo

位置 / 旋转 / 缩放三组 Vec3 输入框右侧各有一个重置按钮（↻），点击把该组恢复为该对象类型的出厂默认值（位置取类型默认位、旋转归零、缩放归 1），并产生一条历史快照以便撤销（DEV-PLAN A3 已实装）。

字段的轴向颜色约定（与 Gizmo 保持一致）：X = 红、Y = 绿、Z = 蓝。

4.7 左侧对象列表

左侧栏两个 Tab：资源库（添加）和 场景（管理已有对象）。场景 Tab 顶部有搜索框，按对象名称实时过滤（大小写不敏感、子串匹配，边输边过滤，清空即恢复全量）；过滤是渲染层派生数据，不写入 store、不产生历史快照。对象列表每条包含：

  • 拖拽排序把手 — 行首，hover 显示（排序见 5.4；已实装，搜索过滤时禁用）
  • 可见性复选框 — 受控绑定 visible，切换即时生效并产生历史快照
  • 颜色圆点 — 显示对象当前颜色
  • 对象名称 — 可点击选中
  • 锁定图标 — 已锁定常显、未锁定 hover 显示开锁样式；点击直接切换 locked（已实装）
  • 两个图标按钮：复制 (⧉) 和 删除 (✕) — hover 或选中时出现；锁定对象的删除按钮置灰

右键菜单（已实装）：在列表项上右键唤出自定义菜单（非浏览器原生），同时选中该对象。菜单项为：重命名 / 复制 / 成组（禁用占位，行为见 6.3）/ 锁定（或解锁） / 删除（锁定时禁用）。点击菜单外区域或按 Esc 关闭。

重命名：点击「重命名」弹出居中输入弹窗（非浏览器 prompt），打开即聚焦；Enter / 确定提交，Esc / 取消 / 点遮罩放弃。名称 trim 后非空且与原名不同才写回，并产生一条历史快照。

操作处理规则
复制 生成新 id，新对象的 name 为 {原名称} 副本，position 相对原对象在 X / Z 方向各偏移 +1，自动成为选中
删除 从 store 中移除；若被删除的是当前选中，则选中清空；生成一条 HistoryEntry
全部清空（顶部工具栏） 弹出二次确认"确定要清空整个场景吗？此操作可通过撤销恢复"；确认后场景重置为默认场景

4.8 撤销 / 重做

操作触发方式规则
撤销Ctrl+Z 或工具栏按钮回退到上一条 HistoryEntry；按钮/快捷键在 historyIndex = 0 时禁用
重做Ctrl+Y 或 Ctrl+Shift+Z 或工具栏按钮前进到下一条 HistoryEntry；在 historyIndex = 末尾 时禁用
历史截断（内部规则）在 historyIndex 之后发生新的可撤销操作时，丢弃所有 redo 分支

以下动作不产生历史快照（属于"视图状态"，撤销没有意义）：改变相机视角、切换 Gizmo 模式、切换资源库 / 场景 Tab。

4.9 保存 / 导入 / 导出（JSON）

操作触发方式规则
导出 JSON工具栏「保存」按钮 → 弹出菜单选「导出 JSON」把当前 Scene 序列化为 JSON 文件，触发浏览器下载，文件名默认 scene-{YYYYMMDD-HHmmss}.json；成功后 Toast 提示。导出内容不含撤销历史（history 属本地会话状态）
导入 JSON工具栏「打开」按钮 → 选择本地 JSON 文件读取文件，校验 schema；校验通过后先弹二次确认（"导入将替换当前未保存的场景（N 个对象），继续？"），确认后替换场景（含环境配置）并清空历史（保留 1 条初始快照作为新会话起点）；成功后 Toast 提示导入对象数
校验失败导入 JSON 不符合 schema（版本不符、字段缺失或取值非法）Toast 报错"文件格式不正确或版本不匹配"，不修改当前场景
自动保存到 localStorage每次产生历史快照时后台静默写入 editor.autosave key（无提示）；页面下次打开时检测到草稿则弹窗询问「恢复上次编辑」

5.3 材质类型切换

P0 所有对象使用 MeshStandardMaterial。P1 允许在属性面板中切换材质类型，并暴露与该材质相关的字段。当前状态：已完成；四种材质均驱动视口真实渲染，材质配置随对象保存、复制、撤销/重做及场景导入导出。

材质暴露的字段说明
MeshBasicMaterialcolor, wireframe不受光照影响，适合做发光/装饰
MeshPhongMaterialcolor, shininess, specularPhong 高光，适合塑料/橡胶感
MeshStandardMaterialcolor, metalness, roughnessPBR，通用
MeshNormalMaterialflatShading用于调试法线方向

每个对象保存一份完整、扁平的 material 配置：type / wireframe / shininess / specular / metalness / roughness / flatShading。默认值依次为 standard / false / 30 / #ffffff / 0.1 / 0.5 / false。切换类型只修改 type，其他类型已调参数继续保留；对象副本深拷贝材质配置，互不影响。

对象顶层 color 保留给 Basic / Phong / Standard 使用；Normal 不显示对象颜色，颜色输入禁用但原值保留。面板仅显示当前材质字段：shininess ≥ 0、metalness / roughness ∈ [0, 1]。数字参数一次完整编辑在 blur / Enter 时提交一条历史，类型与 checkbox 切换立即各提交一条历史。

视图控制条的全局线框强制所有用户对象进入线框，不改写对象材质数据；切回实体后，Basic 自身的 wireframe 仍生效，但不会泄漏到 Phong / Standard / Normal。Normal 的 flatShading 切换即时重建材质着色器。

场景 JSON schema 升级为 1.2。读取 1.1 文件或自动草稿时，缺失的 material 自动补为默认 Standard；非法材质类型、颜色、非有限数值或越界参数均拒绝导入，且不修改当前场景。

5.4 对象列表排序与拖拽

P1 允许在对象列表中拖拽排序；场景渲染顺序不受列表顺序影响，但列表顺序会影响后续功能（分组、层级）的阅读顺序。当前状态：已实装，待手动验收；仅重排 objects 数组，不修改对象属性，也不涉及父子层级。

仅行首把手可发起拖拽。目标行的上半部分表示插入其前，下半部分表示插入其后，并显示对应插入线；源行降低透明度。拖拽不改变当前选中，隐藏和锁定对象仍可排序。Esc 取消、拖出窗口或完成 drop 后清理全部拖拽视觉状态。

搜索过滤期间禁用拖拽，清空搜索后恢复，避免过滤视图的局部索引误排全量数组。拖到自身或相邻原位等顺序不变的落点不产生历史，也不覆盖自动草稿；每次有效排序只产生一条 HistoryEntry 并写一次自动草稿，可由 Ctrl+Z / Ctrl+Y 撤销与重做。

6. 功能需求（P2 · 进阶能力）

P2 需求为方向性描述，暂不进入任何当前迭代。每条标注 P2。

6.1 导入外部模型（GLB / GLTF）

在「资源库」增加一个 📁 导入模型 卡片，点击后弹出文件选择器，只接受 .glb / .gltf。导入的模型作为一个 SceneObject，type 为 model，属性面板支持显示 bounding box 尺寸、缩放、rotation，但不支持材质级别的属性编辑（那个需要更深的资产管线）。

6.2 多选与批量操作

  • Ctrl+点击 多选；Shift+点击 范围多选
  • 选中多个对象时，Gizmo 以"组"为单位进行变换（通过一个 invisible parent group 包装）
  • 属性面板显示"已选中 N 个对象"，允许批量修改 color / visible

6.3 分组 / 父子层级

对象列表变成树形结构。父对象的变换会级联到子对象，但子对象的变换保持自身局部坐标系。分组产生一条 HistoryEntry。

6.4 时间轴动画

底部增加一个时间轴区域。用户可以给某个对象在时间点 t1 设定一组关键帧（position / rotation / scale / color），在 t2 设定另一组，编辑器自动插值。关键帧数据写进 JSON schema 的新字段 animations。 静态版已铺 UI：多轨行（每对象一条轨道）、0–5s 刻度、播放头（静态位置 + 三角帽）、「时长 5s · 1×」标注；数据与插值逻辑按 DEV-PLAN #20 实装。

6.5 渲染导出

  • PNG 截图：把当前 canvas 内容导出为 .png
  • 静态 HTML：生成一个独立的 scene.html + 内嵌 JSON + 最小化 Three.js CDN 引用，双击即可在浏览器打开
  • 透明背景：导出时可选"PNG 带透明背景"，强制关闭 sky / grid / shadow
