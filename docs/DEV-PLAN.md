## 排序说明

- **3（添加）在 4（拾取）之前**：添加入口现成、依赖最少，能立刻验证 store 通路；拾取涉及 raycast 与相机控制的冲突处理，更复杂。
- **8（撤销）独立成步**：快照写入在 5/6/7 中同步埋点，撤销栈本身集中在写操作齐全后一次性验证。
- **16（锁定）排进 P2**：数据字段与 UI 壳已就绪，行为实装依赖拾取（#4）完成。
- **20（时间轴）放最后**：依赖 store、属性绑定、变换写回全部稳定后再做，避免返工。
- **阶段 2.5 紧随阶段 2**：全部是"已付 UI 成本未兑现"的欠账，其中 A1（Viewbar）依赖拾取，可与 #4 同期穿插。
